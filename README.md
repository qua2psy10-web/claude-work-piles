# 杭基礎の設計(H24年道示版)

道路橋示方書・同解説 Ⅳ下部構造編(平成24年3月)に基づく杭基礎設計ソフト。

開発プランは [docs/PLAN.md](docs/PLAN.md) を参照。

## セットアップ・起動

```bash
pip install -e ".[dev]"
streamlit run app/main.py   # リポジトリルートから実行
```

## テスト

```bash
pytest
```

## 構成

- `core/` — 計算エンジン(GUIから独立)
  - `models/` — 地盤・杭・荷重・プロジェクトのデータモデル
  - `soil/liquefaction.py` — 液状化判定(道示Ⅴ(H24) 8.2、FL法・低減係数DE)
  - `capacity/bearing.py` — 軸方向支持力(道示Ⅳ(H24) 12.4)
  - `capacity/springs.py` — Kv・kH・杭頭バネ K1〜K4(道示Ⅳ 9.5、12.6)
  - `capacity/section.py` — 杭種別の断面諸元
  - `capacity/negative_friction.py` — 負の周面摩擦力(道示Ⅳ 12.4.3)
  - `analysis/displacement.py` — 変位法(道示Ⅳ 12.6)
  - `analysis/section_forces.py` — 杭体の断面力分布(Chang の式)
  - `analysis/stability.py` — 安定計算のオーケストレーションと照査
  - `analysis/comparison.py` — 杭種・工法の比較(形式選定の支援)
  - `analysis/level2.py` — レベル2地震時照査(プッシュオーバー解析)
  - `analysis/bnwf.py` — 分布バネモデル(弾性梁 + 弾塑性地盤バネ)
  - `capacity/lateral_limit.py` — 水平地盤反力度の上限値 pHU(道示Ⅳ 12.10)
  - `section/rc.py` — 円形RC断面の応力度(中立軸の反復計算)
  - `section/checks.py` — 杭種別の応力度照査(道示Ⅳ 12.10)
  - `section/shear.py` — せん断照査(円形RC: 道示Ⅳ 5.1.3・5.2.3、鋼管: 2V/A)
  - `section/detailing.py` — 軸方向鉄筋量の構造細目(道示Ⅳ 7.3)
  - `section/pile_head.py` — 杭頭結合部(道示Ⅳ 12.9)
  - `report/` — 計算書生成(Markdown・Excel)
  - `validation.py` — 入力チェック(成立しない入力はエラー、疑わしい入力は警告)
  - `standards.py` — H24道示の定数テーブル(基準年度別に外部化)
- `app/` — Streamlit GUI
- `tests/` — 手計算値との突合テスト、GUIスモークテスト

## ⚠ 実務利用にあたって

計算式・定数は道示H24に基づいて実装しているが、**原典との照合が未完了**の
項目がある。実務適用前に必ず [docs/VERIFICATION.md](docs/VERIFICATION.md) の
チェックリストで照合すること。現時点の制限事項(群杭効果・突出杭・斜杭・
杭頭ヒンジ・有限長の杭・DE の周面摩擦力度への反映など)も同文書に記載。

**でたらめな入力を黙って通さないようにした(第27回)**。杭径 1.0 m の杭を
0.5 m 間隔で配置しても、フーチングから杭がはみ出していても、これまでは
総合判定「OK」を返していた。**照査が無いことより、間違った答えが正しい形式で
出てくることのほうが危険**である。物理的に成立しない入力は計算を中止し、
疑わしい入力は警告として残す。なお**エラー判定は幾何の恒真命題であって
示方書の規定ではない**ため、原典照合を要しない。規定由来の閾値は
杭中心間隔の 2.5D のみで、これは**原典未照合であることを警告文に明示**した
うえで、警告以外には一切使っていない(計算結果に影響しない)。

**原典(道示Ⅳ 4章・5章のスキャン)で許容応力度まわりを総点検した(第23回)**。
これまでの照合はすべて二次資料との突合だったが、初めて原典そのものを参照でき、
**誤りが4件見つかった**。うち3件は非安全側である。

- `TAU_A1_CONCRETE` が約1.5倍(0.35〜0.42 → **0.22〜0.25**)。未使用だったが、
  この値のままでせん断照査を実装していたら非安全側になっていた
- 場所打ち杭の **0.8 倍の低減は道示Ⅳ に存在しない**。水中施工は「呼び強度 →
  設計基準強度」の読替え(表-4.2.5)で考慮されており、低減されるのは付着のみ
- 鉄筋の許容応力度に**荷重組合せ区分がなかった**。SD390 の常時 200(正しくは
  180)、水中・地下水位以下の部材の 160 を扱えず、いずれも非安全側
- `SIGMA_CAG_CONCRETE` の σck 27・30 が 7.0/8.0(正しくは 7.5/8.5)

同時に**ヤング係数比 n = 15(第19回の修正)が原典で裏付けられ**、
せん断照査に必要な式・補正係数表もすべて取得できた。

**液状化層の周面摩擦力を支持力から低減した(第21回、第22回で裏付け)**。
DE が kH にしか効いておらず、液状化すると判定した層からも満額の周面摩擦を
取っていた。既定地層で地震時の Ra が約 6%、引抜き Pa が約 7% 下がる。
f′i = DE,i × fi は提供資料で確認済み。**この低減は耐震設計上の扱いであり、
常時・暴風時の照査には適用しない**(第22回で適用範囲の誤りを修正)。

**非安全側の誤りを1件修正した(第19回)**。場所打ち杭の応力度計算に用いる
ヤング係数比を n = Es/Ec(σck=24 で 8.0)としていたが、道示Ⅲ 3.3 は σck に
よらない一定値 **n = 15** を規定している。鉄筋引張応力度を約 18% 過小評価
していたため修正済み。同時に道示Ⅲ 表-3.3.3 に σck = 50・60 を追加し、
**σck = 80 は同表に存在しない**ことを確定させた(既製杭は Ec を直接入力する)。

当初の調査で「支持力を危険側に評価しているおそれ」として挙げた4件
(中掘り杭の周面摩擦力度、qd 上限値、場所打ち杭の先端1D区間、支持層条件)は
**いずれも提供資料により決着し、修正済み**である(VERIFICATION.md の
第12〜14回)。経緯は同文書の「調査結果サマリ」に残している。

定数は `tests/test_standards_pinned.py` でピン止めしている。定数を修正する
際は同テストの期待値も更新し、VERIFICATION.md に出典を記録すること。
