# 杭基礎の設計(H24年道示版)

道路橋示方書・同解説 Ⅳ下部構造編(平成24年3月)に基づく杭基礎設計ソフト。

開発プランは [docs/PLAN.md](docs/PLAN.md) を参照。

## セットアップ・起動

```bash
pip install -e ".[dev]"
streamlit run app/main.py   # リポジトリルートから実行
```

Python 3.10 以上。

## 使い方

GUI のタブを左から順に進める。

| タブ | 内容 |
|---|---|
| 地盤 | 地層(土質・層厚・N値・単位重量・FC・KEP)と地下水位 |
| 杭・フーチング | 杭種・工法・杭径・杭長・配置・フーチング寸法・材料 |
| 荷重 | 荷重ケースごとの V・H・M(フーチング下面中心) |
| 液状化判定 | FL値と低減係数 DE。以降の地震時照査に反映される |
| 安定計算 | 支持力・変位・杭体応力度・せん断・杭頭結合部 |
| レベル2地震時 | プッシュオーバー解析・降伏判定・応答塑性率 |
| 底版照査 | 底版の曲げ・せん断(**断面力 M・S は入力**) |
| 杭種比較 | 杭種×工法×杭径ごとの必要本数(形式選定の支援) |

サイドバーからプロジェクトの JSON 保存/読込と、計算書(Markdown・Excel)の
出力ができる。安定計算・レベル2を実行してから出力すると、その結果が章として
含まれる。

つまずきやすい点:

- **既製杭(PHC・SC)は σck = 80 が道示Ⅲ の表の範囲外**のため、ヤング係数 Ec の
  直接入力が必要(未入力だとエラー)
- **PHC杭は有効プレストレス σce が必須**(応力度の式そのものに入るため)
- **レベル2で分布バネモデルを使うには全地層に KEP の入力が必要**。1層でも
  欠けると杭頭バネ K1〜K4 による弾性解析に落ちる

計算エンジンは GUI から独立しているので、`core/` をライブラリとしても使える。

```python
from core.analysis.stability import analyze
report = analyze(pile, arrangement, footing, profile, loads, fck=24, material=material)
```

## 構成

- `core/` — 計算エンジン(GUIから独立)
  - `models/` — 地盤・杭・荷重・プロジェクトのデータモデル
  - `soil/liquefaction.py` — 液状化判定(道示Ⅴ(H24) 8.2、FL法・低減係数DE)
  - `capacity/bearing.py` — 軸方向支持力(道示Ⅳ(H24) 12.4)
  - `capacity/springs.py` — Kv・kH・杭頭バネ K1〜K4(道示Ⅳ 9.6、12.6)
  - `capacity/section.py` — 杭種別の断面諸元
  - `capacity/negative_friction.py` — 負の周面摩擦力(道示Ⅳ 12.4.3)
  - `analysis/displacement.py` — 変位法(道示Ⅳ 12.6)
  - `analysis/section_forces.py` — 杭体の断面力分布(Chang の式)
  - `analysis/stability.py` — 安定計算のオーケストレーションと照査
  - `analysis/comparison.py` — 杭種・工法の比較(形式選定の支援)
  - `analysis/level2.py` — レベル2地震時照査(プッシュオーバー解析)
  - `analysis/bnwf.py` — 分布バネモデル(梁 + 弾塑性地盤バネ、kH は節点ごと。
    M-φ を与えると梁も要素ごとに剛性低下する)
  - `capacity/lateral_limit.py` — 水平地盤反力度の上限値 pHU(道示Ⅳ 12.10)
  - `section/rc.py` — 円形断面の応力度(中実・中空 + 鋼材繊維。中立軸の反復計算)
  - `section/checks.py` — 杭種別の応力度照査(道示Ⅳ 12.10)
  - `section/shear.py` — せん断照査(円形RC: 道示Ⅳ 5.1.3・5.2.3、
    鋼管: 2V/A、PHC: τ = S/Ae)
  - `section/moment_curvature.py` — M-φ 骨格曲線(レベル2の塑性ヒンジ)
  - `section/footing.py` — 底版本体の照査(単鉄筋長方形断面の曲げ・せん断)
  - `section/detailing.py` — 軸方向鉄筋量の構造細目(道示Ⅳ 7.3)
  - `section/pile_head.py` — 杭頭結合部(道示Ⅳ 12.9。支圧・押抜きせん断・
    仮想RC断面・定着長・溶接長)
  - `report/` — 計算書生成(Markdown・Excel)
  - `validation.py` — 入力チェック(成立しない入力はエラー、疑わしい入力は警告)
  - `standards.py` — H24道示の定数テーブル(基準年度別に外部化)
- `app/` — Streamlit GUI
- `tests/` — 上記「テスト」を参照
- `docs/VERIFICATION.md` — **照合記録**(58回分。採用した式だけでなく、
  棄却した仮説とその理由・確度も残している)

## ⚠ 実務利用にあたって

計算式・定数は道示H24に基づいて実装しているが、**原典との照合が未完了**の
項目がある。実務適用前に必ず [docs/VERIFICATION.md](docs/VERIFICATION.md) の
チェックリストで照合すること。現時点の制限事項(群杭効果・突出杭・斜杭・
杭頭ヒンジ・有限長の杭・DE の周面摩擦力度への反映など)も同文書に記載。

**底版(フーチング)本体の許容応力度法照査を新規実装した(第58回)**。全サンプル
に必ず現れながら一貫して対象外としてきた、最後の大きな未実装領域。Kui_8の
7章を出典に、単鉄筋長方形RC断面としての**曲げ応力度**(中立軸・σc・σs・必要
鉄筋量)、**最小鉄筋量**(Mu≧Mc または 1.7M≦Mc、かつ500mm²/m)、**せん断応力度**
(`τa=ce·cpt·cdc·τa1`)を実装し、計算例の2断面すべてで厳密に一致した(せん断は
Scaまで小数2桁一致)。ce・cptの表は杭体のせん断照査と同一で既存定数を再利用でき、
新規定数はせん断スパン比の割増し係数cdcのみ。

副産物として**`σbt = 0.23·σck^(2/3)`が7桁で厳密に裏付けられた**——第54回に
M-φのひび割れモーメントから確認しようとして1.5%合わず、利用者入力に委ねた式。
長方形断面には換算断面の丸めが無いため厳密に確かめられ、当時のずれがPHC杭の
Ae・Zeの表示桁数由来だったことも確定した。終局モーメントMuは等価応力矩形ブロック
だと0.04%ずれ、道示Ⅲの放物線＋矩形分布を積分すると0.004%まで詰まる。

**断面力M・Sは入力**とし、杭反力・自重から各照査位置のM・Sを求める計算は実装
していない——原典が格点モデル(5杭列×2柱)で解いており、柱の位置・寸法という
本ソフトが持たない諸元を要し、単純な片持ち梁近似では検証できないため。必要
斜引張鉄筋量も式が読み取れず全ケースでSh'=0だったため、「必要である」旨の
提示に留めた。GUIに「底版照査」タブを新設。

**新サンプルKui_12(場所打ち杭φ1200)で、負の周面摩擦力度fn=10・N(粘性土)
を実データで確認し、確度をCからBに格上げした(第57回)**。2.4「負の周面
摩擦力に対する検討」に、粘着力未入力の粘性土2層(N=2.0→fn=20.0、
N=3.8→fn=38.0)のデータがあり、既存の推定式`fn=10・N`と2点とも厳密に
一致した。同じ節には`1.2・(Po+Rnf+W')≦σy・Ap`という杭体応力度ベースの
別の照査もあったが、本ソフトのNF_SAFETY_FACTOR=1.2は地盤支持力Ruを
除する別種の照査に使っており、直接の裏付けにはならないため実装は
見送った。底版照査・7章レベル2続きは既存の対象外方針どおり。

**新サンプルKui_11(SC杭φ700・単一杭種)で、杭体から決まる支持力の上限値
(Rpu・Ppu)をSC杭に対応させた(第56回)**。従来SC杭は「式が確認できて
いない」として拒んでいたが、Kui_11の7.7.4/7.7.5に
`Rpu=0.85・σck・Ac+σy・As=19578kN`・`Ppu=σy・As=8812kN`とAc・As・σck・σyの
具体的な入力値つきで明記されており、場所打ち杭・PHC杭と同型の式(コンクリート
の負担項を持つ)であることが分かった。`run_level2()`の自動配線にもSC杭を
追加した。qd・fi・杭頭結合部の応力度照査・定着長・溶接長は既存の式に
すべて一致(σck=30、τoa=1.8、D32という初めて確認した値でも厳密に一致)。
fiは今回も既存の推定式と一致しない値が並び、「fは自由入力」という結論の
反例がまた1つ増えた。

**PHC杭のせん断照査を新規実装した(第55回)**。前回(第53回)Kui_10の
検証で読み取っていた未使用のデータ(τ=S/Ae、軸方向圧縮力による補正係数
CN=1+Mo/M(Mo=(σce+N/Ae)・Ie/y、1≦CN≦2))をもとに`check_phc_shear()`
として実装した。許容せん断応力度の基本値0.85N/mm²は`PRECAST_CONCRETE_
ALLOWABLE["PHC杭"].shear`として以前から定義済みだったが、どこからも
参照されておらず今回初めて使われる形になった。Kui_10の橋軸・橋軸直角
方向、計5ケースすべてでτ・τaが計算例と厳密に一致した。Ae・Ieは曲げ
応力度照査と共通の値(`phc_effective_section()`として切り出し)を使う。
SC杭のせん断照査はプレストレスを持たない合成断面でMoの式がそのまま
適用できるか未確認のため見送った。

**フェーズ4: レベル2地震時照査の最大の未実装項目だった「杭体の曲げ非線形
(M-φ)」を実装した(第54回)**。従来、軸方向バネと水平地盤バネの塑性化は
追跡していたが杭体だけは弾性のままで、**杭体が全塑性モーメントを超える
モーメントを負担できてしまい、降伏水平力を過大に評価していた**(非安全側)。
M-φ骨格曲線を与えると、分布バネモデルの梁要素ごとに割線曲げ剛性を低下させる
(塑性ヒンジ)。鋼管杭の例で、従来は最大杭頭モーメントが全塑性モーメントを
43%超過していたのが、正しくMuで頭打ちになることを確認した。曲率は変位場から
直接求める実装とし(剛性に依存しないため反復が安定)、微小変位では弾性解と

> ⚠ **引抜き側は未解明。** 設計極限引抜力 PTu = 4195 kN に対し、本ソフトの
> Pt = Ruf + W はどの条件でも合わない。5.3「許容支持力・引抜力の計算」の章が必要。
> 押込み側だけ裏付けが取れた状態である。

未実装項目の**目標値**も得られた — RC系杭のトリリニア M-φ(Mc/φc・My/φy・Mu/φu を
死荷重時と軸力0時の両方)、仮想RC断面(Do = D + 200mm)の引張軸力ケースの σs、
杭頭補強鉄筋の定着長(τoa = 1.600)。

**H24版の通しの計算例と、kH から応力度までの連鎖が一致した(第34回)**。
場所打ち杭 φ1200・L=25m・12本の計算書サンプルに対し、層ごとの kH(8通り)・
杭軸方向バネ Kv・変位・杭反力・杭頭モーメント・鉄筋断面積・応力度まで
**すべて 1% 以内**(多くは 0.01% 以内)で一致した。外部の独立実装と連鎖全体を
突き合わせられたのは初めてである。

> ⚠ **計算例の K1〜K4 は Chang の半無限長式ではなかった。** K1・K2・K4 から
> 逆算した β が3通りで食い違い、恒等式 K1·K4 = 2·K2² も成り立たない。
> **層ごとの kH をもつ有限長の数値解**である。本ソフトの分布バネモデル(BNWF)に
> 層ごとの kH を与えて杭頭剛性に縮約すると **0.1% で再現**した。一方、許容応力度
> 設計法の経路は単一 kH の Chang なので **K2・K4 を 5〜6% 小さく評価する**。
> 第30回に「Chang の式は一様地盤の仮定と不可分」と制限に書いたとおりの現れ方で、
> その差の大きさが数値で確認できた(対応は原典照合待ちとして保留)。

> **変位法ソルバー自体には誤りがない**ことが確定した。計算例の K1〜K4・Kv を
> そのまま与えると変位・杭反力・杭頭モーメントが 0.005% 以内で一致する。
> このとき K2 の符号(本ソフトは負、計算例は絶対値表示)でつまずき、
> **釣合いは満たすのに解が違う**という状態になった。釣合いの検算だけでは
> 符号規約の誤りを検出できない。

同時に、**鉄筋の公称断面積を取り違えていたのを修正した(第34回)**。異形棒鋼は
リブ・節があるため公称断面積は呼び名の直径の円の面積と一致せず、D25 は
**506.7 mm²**(π·25²/4 = 490.9 mm² より 3.2% 大きい)。JIS G 3112 の表を持たせた
(計算例の 121.608 cm² と完全一致し、公称質量 ÷ 7.85 g/cm³ とも全径で 0.3% 以内)。
応力度は安全側に出ていたが、**軸方向鉄筋量の照査では配置量を 3.2% 過小に見て
いた**。

計算例の作法も3点確定した — 第1断面の σc・σs は**押込み軸力が最小の杭**から
取る(最大ではない)、地中部最大曲げは**杭頭ヒンジ**の解析から出ている
(本ソフトは剛結のみ・未対応)、換算断面積は Ac + n·As で鉄筋の占める
コンクリートを控除しない(本ソフトは控除する = 安全側なので追随しない)。

**他社製品の計算書サンプルと許容応力度表が9項目一致した(第33回)**。
場所打ち杭 φ1200・σck=24・SD345 のサンプル1章に対し、σca(8.00/12.00)・
τa1(0.230)・τa2(1.700/2.550)・n(15.00)・許容水平変位(15.0mm)、そして
**σsa 引張が常時 160 → 地震時 300**(160×1.5=240 ではない)まで一致した。
第23回の τa1 の下方修正と、第20回の n = 15 への修正が、別実装から裏付けられた。

同時に、**鉄筋の許容曲げ圧縮応力度の照査が抜けていたので追加した(第33回)**。
場所打ち杭では n·σca = 15×8.0 = 120 < 200 で決して支配しないが、
**RC杭では n·σca = 15×13.5 = 202.5 で 200 に接する**ため包含が崩れる。
σck=24 だけを見て「不要」と結論しかけたが、第31回に実装した RC杭で崩れることに
気づいて撤回した。値 200 は他社出力から読み取ったもので**原典未照合(確度B)**、
全材質に適用(材質が上がると許容値は大きくなるので安全側)。

**H29版の設計計算例と kH の連鎖が数値で一致した(第32回)**。鋼管杭・鋼矢板
技術協会の計算例(φ1000・t14・L=39.9m・7層地盤)に対し、β = 0.17852(計算例
0.17853)、B' = 2.367 m(同 2.367)、層ごとの kH は 13 通りすべて **0.01% 以内**で
一致した。とくに計算例の換算載荷幅の列が**全層で同一**であることが、
**第29回(BH は常時の条件で1回だけ決める)と第30回(kH は層ごと)の独立な
裏付け**になった。

> ⚠ **この計算例は H29版(限界状態設計法・部分係数設計法)である。** 本ソフトは
> H24版の許容応力度設計法が対象なので、**式と手順が両版で同一の部分に限って**
> 使った。とくに**軸方向バネ定数 Kv は H29版で式そのものが変わっている**
> (計算例は先端伝達率 γy と補正係数 ζe・ζd による別式)ため、一切突合していない。
> 部分係数・制限値・pHU の補正係数・応答塑性率の制限値も対象外。

同時に、**腐食しろを内面から控除していた誤りを修正した(第32回)**。計算例の
Is = 0.00488 m⁴ を再現するには、腐食しろを**外面から**控除して外径 1.000 →
0.998 m・板厚 14 → 13 mm・内径は 0.972 m のまま(6桁まで一致)としなければ
ならない。本ソフトは外径を変えず板厚だけ減らしていたため、**断面二次モーメント
を 0.60%、断面係数を 0.41% 過大に評価していた = 応力度を小さく見せる非安全側**
だった。地中の鋼管杭は外周面が腐食するのだから物理的にも外面控除が正しい。
`corroded_tube()` に一元化し 5 か所を揃えた(杭径 D 自体には反映しない —
計算例も B' の算定には公称の D = 1.000 m を使っている)。

**RC杭・SC杭の杭体応力度照査を実装した(第31回)**。断面解析を中実円形から
**中実・中空のコンクリート + 鋼材繊維**に一般化し、場所打ち杭(中実+鉄筋)・
RC杭(円環+鉄筋)・SC杭(円環コンクリート+外側の鋼管)を同じ解法で扱う。
いずれもコンクリートは圧縮のみ有効なひび割れ断面とする(RC杭・SC杭は許容
曲げ引張応力度の規定がないことと整合し、鋼材の応力度を大きく評価する安全側)。
検証は**独立な数値積分で釣合いを積み直す**方法で行った(σ を断面全体に
積分し直して N・M に戻ることを確認)。応力度照査が未実装の杭種は H鋼杭のみ。

> ⚠ **SC杭の外殻鋼管の許容応力度は「値」ではなく「適用範囲」が未照合。**
> 道示Ⅳ 表-4.4.1(第23回に原典照合済み)は SKK400 = 140、SKK490 = 185
> N/mm² を定め、SC杭の外殻鋼管の材質もこの2種である。よって同表を適用して
> いるが、**同表が SC杭の外殻鋼管に及ぶことは確認できていない**(第31回に
> 検索したが一次資料は取得できず)。真の許容値が小さければ非安全側になるため、
> 照査結果に必ず注記を付し、`MaterialSpec.sc_steel_allowable` で直接
> 指定できるようにした。

> 中空にすると σc は上がるが**鉄筋の引張応力度は下がる**。圧縮域の面積が
> 減るぶん中立軸が引張側へ深く入り、引張鉄筋が中立軸に近づくためである。
> 直感に反するので、釣合いの独立検証とセットでテストに記録した。

**分布バネモデルの kH を深度ごと・地層ごとに求めるようにした(第30回)**。
第29回の資料の計算手順は kH を**当該深度の地層の E0** から求めると定めて
いるが、本ソフトは杭長にわたって単一の kH(設計地盤面から 1/β の区間で
平均した E0 による値)を用いていた。Chang の式は地盤が一様であることを
前提とするため単一値でしか解けないが、**分布バネモデルにはその制約がない**。
換算載荷幅 BH は「杭が地盤を押し広げる幅」であって地層の性質ではないため、
常時の条件で定めた共通値を全深度で使い回す(層ごとに求め直さない)。

> 表層に軟弱層がある地盤では、これは**非安全側の平均化**だった。N値
> 3/10/5/45 の4層地盤で試すと、kH は 13,968〜209,515 kN/m³ の範囲に散る
> のに対し、単一値は 37,632 kN/m³ 一つである。層ごとに与えると設計レベル2
> 荷重時の水平変位が 5.91 → 6.71 mm(+13%)、杭頭モーメントが 232 → 334
> kN·m(**+44%**)になった。平均が浅部の軟弱層を実際より硬く評価していた
> ためである。なお Chang の式(K1〜K4)を使う許容応力度設計法の経路は
> 一様地盤の仮定と不可分なので、単一値のままとし、制限として明記した。

**換算載荷幅 BH を地震時の α で反復していた誤りを修正した(第29回)**。
道示Ⅳ 9.6 は **BH を求める kH に常時の値を用いる**と定めており、地震時も
同じ BH を使う。本ソフトは地震時の α = 2 で BH まで反復し直しており、
正のフィードバックにより **kH ∝ α^(32/29)** となって、2 倍のはずの kH が
2.149 倍になっていた。**kH が 6.9%、K1 が 5.2% 過大 = 地盤を硬く評価する
非安全側**である。修正後は kH(地震時)= kH(常時)× 2 ちょうど、BH は
全ケースで同一、β の比は 2^(1/4) となる(いずれも 1e-12 でテスト固定)。

> このとき、既存のテストは `test_seismic_alpha_doubles_kh`(「2倍になる」)
> という名前でありながら中身は `assert seismic.kh > normal.kh` だった。
> **名前は正しく、アサーションが緩かった**ため、7% の系統誤差が 444 件の
> テストを素通りしていた。大小関係で済ませたテストは比の狂いを検出できない。

同時に、**レベル2用の kH という長年の宿題が解消した(第29回)**。
レベル1・レベル2とも **α = 2** が正しい扱いであることが資料で確認でき、
「レベル1の値を流用している疑い」は誤解だった。残っていた差(深度ごと・
地層ごとの kH)は第30回に解消した。

**地域別補正係数を 1.0 で頭打ちにしていた誤りを修正した(第28回)**。
道示Ⅴ 4.4 の cIz は **A1・B1 地域で 1.20** だが、入力を 1.0 に制限しており
これらの地域を表現できなかった。液状化判定のせん断応力比 L が 17% 小さく、
FL が 20% 大きく出るため**非安全側**である(既定地層では深さ 4.5 m の
DE が 0.333 → 0.000 に変わる)。地域区分を選べば表から引けるようにした。

同時に、**杭中心間隔 2.5D の意味を取り違えていたことが分かった(第28回)**。
2.5D は最小寸法の規定ではなく、**群杭としての影響を考慮する義務が生じる
境界**である。あわせて水平方向地盤反力係数の補正係数
μ = 1 − 0.2(2.5 − L/D)を実装した(分布バネモデルには適用しない)。
**群杭影響のもう一方である「仮想ケーソン基礎とみなした押込み支持力の上限」は
未実装であり、非安全側に残っている。**

> ⚠ **kH には別物が二つある。** 杭の水平抵抗に使う**水平方向地盤反力係数**
> kH(kN/m³、道示Ⅳ 9.6)と、慣性力・土圧に使う**設計水平震度**
> kH(khc・khg、無次元、道示Ⅴ 6.4.3)である。第28回の資料は後者、
> 第29回の資料は両方を扱っている。混同すると「解決済み」と誤認しかねない。

**でたらめな入力を黙って通さないようにした(第27回)**。杭径 1.0 m の杭を
0.5 m 間隔で配置しても、フーチングから杭がはみ出していても、これまでは
総合判定「OK」を返していた。**照査が無いことより、間違った答えが正しい形式で
出てくることのほうが危険**である。物理的に成立しない入力は計算を中止し、
疑わしい入力は警告として残す。なお**エラー判定は幾何の恒真命題であって
示方書の規定ではない**ため、原典照合を要しない。規定由来の閾値は
杭中心間隔の 2.5D のみである(第28回で意味と出典を確定させた)。

**原典(道示Ⅳ 4章・5章のスキャン)で許容応力度まわりを総点検した(第23回)**。
これまでの照合はすべて二次資料との突合だったが、初めて原典そのものを参照でき、
**誤りが4件見つかった**。うち3件は非安全側である。

- `TAU_A1_CONCRETE` が約1.5倍(0.35〜0.42 → **0.22〜0.25**)。未使用だったが、
  この値のままでせん断照査を実装していたら非安全側になっていた
- 場所打ち杭の **0.8 倍の低減は道示Ⅳ に存在しない**。水中施工は「呼び強度 →
  設計基準強度」の読替え(表-4.2.5)で考慮されており、低減されるのは付着のみ
- 鉄筋の許容応力度に**荷重組合せ区分がなかった**。SD390 の常時 200(正しくは
  180)、水中・地下水位以下の部材の 160 を扱えず、いずれも非安全側
- `SIGMA_CAG_CONCRETE` の σck 27・30 が 7.0/8.0(正しくは 7.5/8.5)

同時に**ヤング係数比 n = 15(第19回の修正)が原典で裏付けられ**、
せん断照査に必要な式・補正係数表もすべて取得できた。

**液状化層の周面摩擦力を支持力から低減した(第21回、第22回で裏付け)**。

f′i = DE,i × fi は提供資料で確認済み。**この低減は耐震設計上の扱いであり、
