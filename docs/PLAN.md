# 杭基礎設計ソフト 開発プラン

道路橋示方書・同解説 Ⅳ下部構造編(平成24年3月)に基づく杭基礎の設計計算ソフトを開発する。
参考製品: 綜合システム「杭基礎の設計(H24年道示版)」
(https://www.sogonet.co.jp/products/kuikiso_h24/)

---

## 1. 目的とスコープ

- 橋脚・橋台の杭基礎について、**常時・暴風時・レベル1地震時**の安定計算(変位法)と
  部材設計を行い、設計計算書を出力する。
- **レベル2地震時照査**(基礎の降伏判定・応答塑性率照査)は後期フェーズで対応する
  (参考製品では別売の「杭基礎の耐震設計」に相当する範囲)。
- 準拠基準:
  - 道路橋示方書・同解説 Ⅳ下部構造編(H24.3)
  - 道路橋示方書・同解説 Ⅴ耐震設計編(H24.3) … 液状化判定・L2照査
  - 杭基礎設計便覧(H27.3)
- **注意**: 最新の道示はH29(平成29年)版で部分係数法に移行している。本ソフトは
  参考製品に合わせて**H24版(許容応力度法)準拠**とするが、計算エンジンは
  照査ロジックを差し替え可能な構造とし、将来のH29対応の余地を残す。

### 決定事項(2026-08-11)
- 準拠基準は **H24版** で確定(H29対応は将来拡張)
- **GUI先行**で開発する(CLIのみの期間を設けず、初期からGUIで入力・実行できる形にする)

## 2. 対応範囲(参考製品の機能分析より)

### 杭種(7種)
| 杭種 | 断面照査 |
|---|---|
| 鋼管杭 | 鋼管応力度(腐食代控除) |
| 鋼管ソイルセメント杭 | 鋼管応力度 |
| 場所打ち杭 | RC断面(許容応力度) |
| PHC杭 | PC断面 |
| SC杭 | 合成断面 |
| RC杭 | RC断面 |
| H鋼杭 | 鋼断面 |

### 施工工法(7種)
打込み(打撃)/ バイブロハンマ / 場所打ち / 中掘り / プレボーリング /
鋼管ソイルセメント / 回転杭

工法により支持力推定式・周面摩擦力度・杭先端条件・Kv算定係数が異なる。

### 荷重ケース
常時 / 暴風時 / レベル1地震時(震度法)。各ケースで許容応力度の割増係数を適用。

## 3. 計算機能一覧(計算フロー順)

1. **設計条件・地盤モデル**
   - フーチング形状・根入れ、杭配置(矩形配置・千鳥)、杭寸法・材質
   - 地層データ: 層厚、土質区分、N値、γ、c、φ、変形係数E0
   - 設計地盤面、地下水位、設計水平震度
2. **液状化判定**(道示Ⅴ編)
   - FL法による判定、土質定数の低減係数DEの算定、耐震設計上の地盤面
3. **杭の軸方向許容支持力**
   - 工法別の極限支持力式(先端支持力度qd、周面摩擦力度f)
   - 押込み支持力Ra・引抜き抵抗力Pa(安全率は荷重ケース別)
   - 負の周面摩擦力(NF)の検討(圧密沈下層がある場合)
4. **バネ定数**
   - 軸方向バネKv(工法別のa = f(L/D)式)
   - 水平方向地盤反力係数kH(換算載荷幅BH = √(D/β)、収束計算)
   - 杭軸直角方向バネK1〜K4、基礎全体の連成バネ
5. **安定計算(変位法)**
   - 杭頭剛結/ヒンジ、フーチング剛体仮定の変位法により
     各杭の杭頭反力(軸力・水平力・モーメント)と変位を算定
   - 照査: 押込み・引抜き支持力、杭頭水平変位(常時15mm等の目安)
6. **杭体の断面計算**
   - 深度方向の断面力分布(Changの式系の地中部曲げモーメント分布)
   - 杭種別の応力度照査、必要鉄筋量、鉄筋段落し
7. **杭頭結合部の計算**
   - 結合方法B(仮想RC断面)を基本に、押抜きせん断・水平支圧等の照査
8. **レベル2地震時照査**(後期フェーズ)
   - 杭のM-φ(トリリニア)、地盤抵抗の上限値(押込み・引抜き・水平)
   - 基礎の降伏判定、応答塑性率・応答変位の照査(タイプⅠ/Ⅱ地震動)
9. **付帯機能**
   - 杭種・工法の比較表(概算数量・適否)、形式選定支援(参考製品tab02相当)

## 4. 入出力

- **入力**: GUIフォーム(設計条件・地層・杭配置・荷重)。入力内容はJSONスキーマに
  シリアライズし、プロジェクトファイルとして保存・再読込できるようにする。
- **出力**:
  - 設計計算書(Markdown → PDF/Excel)。式・代入値・判定(OK/NG)を明記
  - 中間結果のJSON出力(検証・他ソフト連携用)

## 5. アーキテクチャ(GUI先行構成)

```
repo/
├── core/            # 計算エンジン(Python パッケージ、GUIから独立)
│   ├── models/      # pydantic データモデル(地盤・杭・荷重)
│   ├── soil/        # 液状化判定・地盤定数
│   ├── capacity/    # 支持力・バネ定数
│   ├── analysis/    # 変位法・断面力分布
│   ├── section/     # 杭種別断面照査
│   └── report/      # 計算書生成
├── app/             # Streamlit GUI(入力フォーム・結果表示・計算書DL)
└── tests/           # 道示計算例・便覧例題との突合(coreのみを対象)
```

- **言語**: Python 3.12+(数値計算・帳票生成のライブラリが充実、検証しやすい)
- **GUI**: まず **Streamlit** を採用。Pythonだけで表形式入力・図表表示・
  ファイルDLまで作れるため、計算機能と同時並行でGUIを育てられる。
  将来、配布形態や操作性の要求が高まったら FastAPI + React へ移行
  (coreを分離しておくのはこのため)。
- 計算エンジンは**純粋関数+immutableなデータモデル**で構成し、
  1計算ステップ=1関数=1テストの粒度を保つ。GUIコードに計算式を書かない。
- 許容値・安全率・係数類は基準年度別の**定数テーブルとして外部化**(H29対応の布石)

## 6. 開発フェーズ(GUI先行)

| フェーズ | 内容 | 成果物 |
|---|---|---|

## 7. 検証方針

- 道示Ⅳ編の参考資料・杭基礎設計便覧の**例題を回帰テスト化**し、手計算値と突合
- 市販ソフト(参考製品等)の出力が入手できる場合は同一条件で突合
- 単体テスト: 支持力式・バネ定数・変位法の剛性マトリクスを式単位で検証

## 8. リスク・論点

1. **H24 vs H29**: 実務で今後H29(部分係数法)が求められる可能性が高い。
   → 定数外部化と照査層の分離で移行コストを抑える(§5)。
2. **変位法の検算**: 杭頭ヒンジ・斜杭・突出杭など条件分岐が多い。
   → まず直杭・杭頭剛結に限定して基礎を固め、順次拡張。
3. **示方書の式の転記ミス**: 最大のリスク。式ごとに出典(道示の式番号)を
   docstringに記録し、レビュー可能にする。加えて `docs/VERIFICATION.md` に
   全定数の確度と照合状況を一覧化し、**原典照合を完了するまで実務利用しない**
   運用とする。
4. **液状化判定の地震動タイプ別処理**(L1/L2、タイプⅠ/Ⅱ)は早期にモデル化して
   おかないと後付けが困難。フェーズ0に含めた理由。
