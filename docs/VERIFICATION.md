# 検証チェックリスト(原典照合が必要な定数・式)

本ソフトの計算式・定数は道路橋示方書(H24)に基づいて実装しているが、
**実務適用前に原典との照合が必須**である。特に下表の「要照合」項目は、
実装者の記憶に基づく値を含むため、必ず示方書本文と突き合わせること。

照合が済んだ項目は「照合済」欄に日付とページ番号を記入する。

# 【重要】2026-08-11 調査結果サマリ

## この調査の限界

道路橋示方書は市販図書であり、**原典そのものは参照していない**。本調査は
Web 検索経由で得られた公開二次資料(国総研資料・土木研究所資料・業界団体の
技術資料等)の要約との突合にとどまる。したがって以下の結果は
**「原典照合」ではなく「二次資料との整合性チェック」**である。
最終的な照合は、示方書本文を持つ技術者が行う必要がある。

なお本実行環境ではネットワークポリシーにより外部サイトへの直接アクセスが
遮断されており、資料PDFの本文は取得できていない(検索エンジンの要約のみ)。

## ⚠️ 食い違いが見つかった項目(**要修正の可能性**)

コード上の該当箇所には `要確認` コメントを付記済み。**修正はせず、原典確認を
待っている状態**(誤った推測で上書きすると被害が大きいため)。

### 1. 中掘り杭(セメントミルク噴出撹拌方式)の周面摩擦力度

| | 砂質土 | 粘性土 |
|---|---|---|
| 実装(`_F_CEMENT`) | 10N(≦200 kN/m²) | 0.8c(≦100 kN/m²) |
| 二次資料 | **3N(≦150 kN/m²)** | **c または 10N(≦100 kN/m²)** |

出典: 鋼管杭・鋼矢板技術協会/TBS工法協会の技術資料。
砂質土側は実装値が**約3倍過大**であり、支持力を危険側に評価している
おそれがある。**優先度: 最高**。

### 2. 中掘り杭・プレボーリング杭の qd 上限値

| | 実装 | 二次資料 |
|---|---|---|
| qd 上限 | 12,000 kN/m² | **10,000 kN/m²**(qd = 200N として) |

出典: 国総研資料 ks1174「道路橋における基礎の施工法と設計法の変遷」。
実装値が危険側。**優先度: 高**。

### 3. 場所打ち杭の支持層条件・適用範囲(未実装)

H24 改定で場所打ち杭の支持層の記述が
「良質な粘性土層」→「**粘性土層(N ≧ 20、qu ≧ 0.4 N/mm²)**」に変更され、
適用杭径は **φ400〜1200mm** とされている。本ソフトは支持層の妥当性を
検証しておらず、N値の小さい粘性土層を支持層にしても警告が出ない。
**優先度: 中**(入力チェックとして追加すべき)。

### 4. 場所打ち杭の先端付近の周面摩擦(未実装)

H24 では場所打ち杭について
「**杭先端から杭径 1D 分の区間の周面摩擦力は押込み支持力に見込まない**」
とされている。本ソフトは杭頭から杭先端まで全長で周面摩擦を計上しており、
支持力を危険側に評価している。**優先度: 高**。

## ❓ 検索では特定できなかった項目

以下は具体的な数値表が公開資料に現れず、確認できなかった。
**すべて原典での確認が必要**である。

- 工法別の qd・f の推定式全般(打込み杭の qd = 130N を含む)
- 安全率表(常時 3/6、暴風時・地震時 2/3)
- 各種許容応力度(コンクリート・鉄筋・鋼材)、場所打ち杭の低減係数 0.8
- 杭頭結合部の照査式・許容押抜きせん断応力度
- 負の周面摩擦力度 fn、NF 考慮時の安全率 1.2
- 液状化判定の khg0、低減係数 DE の表

## 定数変更時の運用

`tests/test_standards_pinned.py` が全定数の現在値をピン止めしている。
定数を修正する際は同テストの期待値も更新すること。これにより、
定数変更が必ずレビュー対象の差分として現れる。

## 未実装・簡略化している事項

以下はフェーズ2時点での制限。実務利用にはこれらの実装が必要。

1. **群杭効果**による支持力・地盤反力の低減
2. **突出杭・斜杭・杭頭ヒンジ**(現状は直杭・杭頭剛結のみ)
3. **有限長の杭**(βLe < 3)の K1〜K4(現状は半無限長式のみ。
   `LateralSprings.is_semi_infinite` で判定は可能)
4. **液状化に伴う土質定数の低減**の安定計算への反映
   (DE は算定済みだが、kH・支持力への反映は未実装)
5. **杭頭結合部の詳細**(結合方法A/B の区別、杭頭鉄筋量の算定、
   仮想RC断面の照査)
6. **鉄筋の段落し**(地中部最大曲げ位置は算定済みだが、段落し位置の
   自動決定は未実装)
7. **せん断力に対する照査**(コンクリートの平均せん断応力度、
   帯鉄筋量の算定)
8. **引張軸力を受ける断面**の応力度計算(`analyze_circular_rc` は
   圧縮軸力のみ対応)
9. **場所打ち杭以外のRC系杭種**(PHC・SC・RC杭)の断面照査(フェーズ3)
10. **レベル2地震時照査**(フェーズ4)
