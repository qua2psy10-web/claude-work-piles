# 検証チェックリスト(原典照合が必要な定数・式)

本ソフトの計算式・定数は道路橋示方書(H24)に基づいて実装しているが、
**実務適用前に原典との照合が必須**である。特に下表の「要照合」項目は、
実装者の記憶に基づく値を含むため、必ず示方書本文と突き合わせること。

照合が済んだ項目は「照合済」欄に日付とページ番号を記入する。

## 凡例

- **確度A**: 式の形・値ともに確度が高い(広く引用される基本式)
- **確度B**: 式の形は確実だが、係数・上限値の照合が必要
- **確度C**: 実装者の記憶に依存する。**必ず照合すること**

## 未実装・簡略化している事項

以下はフェーズ1時点での制限。実務利用にはこれらの実装が必要。

1. **杭体の断面力分布・応力度照査**(フェーズ2)
2. **杭頭結合部の照査**(フェーズ2)
3. **負の周面摩擦力(NF)の検討**(フェーズ2)
4. **群杭効果**による支持力・地盤反力の低減
5. **突出杭・斜杭・杭頭ヒンジ**(現状は直杭・杭頭剛結のみ)
6. **有限長の杭**(βLe < 3)の K1〜K4(現状は半無限長式のみ。
   `LateralSprings.is_semi_infinite` で判定は可能)
7. **液状化に伴う土質定数の低減**の安定計算への反映
   (DE は算定済みだが、kH・支持力への反映は未実装)
8. **レベル2地震時照査**(フェーズ4)
