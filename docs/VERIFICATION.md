# 【第11回】2026-08-11 提供資料(杭頭結合部)— 抵抗機構が整理、実装の誤りを修正

最大の弱点だった杭頭結合部について、**規定の枠組みが明確になった**。
実装の照査項目に位置づけの誤りが見つかり、修正した。

## 条項の確定

**道示Ⅳ 下部構造編 12.9.3「杭とフーチングの接合部」**。
従来コードは「12.9」としていたため 12.9.3 に修正した。
Ⅲ編(コンクリート橋編)には杭頭結合部の規定は無い。

## ✅ 実装の前提が一致していた項目

- **原則として剛結**とする → 変位法で杭頭剛結を仮定しており一致
- 標準は従来「方法B」と呼ばれた方法。**埋込み長は最小限(目安 100mm)**、
  主として杭頭補強鉄筋で杭頭曲げモーメントに抵抗
  → 実装の既定埋込み長 0.1 m と一致

## 🔧 実装の誤りを修正: 支圧の位置づけ

資料が示す作用と抵抗機構:

| 作用 | 主な抵抗の考え方 |
|---|---|
| **押込み力** | フーチングコンクリートの**支圧・押抜きせん断** |
| 引抜き力 | 杭頭補強鉄筋などの引張抵抗 |
| 水平力・モーメント | 補強鉄筋、仮想RC断面、フーチングの水平押抜きせん断 |

従来の実装は「**水平支圧応力度**」として *水平力* を杭頭側面の投影面積で
除した値を照査していた。しかし資料の枠組みでは**支圧は押込み力に対する
抵抗機構**であり、水平力・モーメントに対しては補強鉄筋・仮想RC断面・
水平押抜きせん断が受け持つ。**根拠のない照査だった**ため差し替えた。

- 削除: 杭頭水平支圧応力度(= 水平力 /(D × 埋込み長))
- 追加: **杭頭支圧応力度**(= 押込み軸力 / 杭断面積、許容値は安全側に σca)

## 🔧 新規実装: 縁端距離の確認

資料より:

> 最外周杭のフーチング縁端距離について、杭径 D の 1.0 倍を標準的な値として
> 扱う考え方がある。**縁端距離が D 未満の場合は、フーチングの水平方向
> 押抜きせん断を照査する。** レベル2地震動を考慮する対象では、この
> 押抜きせん断もレベル2地震動まで照査する。

対応:
- `edge_distances()` でフーチング寸法と杭配置から縁端距離を算定
- 1.0D 未満の場合、GUI と計算書に**水平方向押抜きせん断の照査が必要だが
  未実装である**旨の警告を出す

これにより、従来は黙って見逃していた条件を利用者に提示できるようになった。

# 【第10回】2026-08-11 提供資料(α の解説)— **α が確定、推定方法別の表を実装**

長らく未確認だった α が確定した。加えて **α は E0 の推定方法により変わる**
という、実装に欠けていた重要な情報が得られた。

## ✅ α = 1.0 / 2.0 は正しかった(確度 C → A)

実装の α(常時 1.0 / 地震時 2.0)は、**N 値から E0 = 2800N として推定する
場合の値**として確認された。本ソフトの既定の推定方法と一致する。

式も一致:
- `kH0 =(1/0.3)× α × E0` ✓
- `kH = kH0 ×(BH/0.3)^(−3/4)` ✓

数値例による突合も一致した(E0 = 28,000 kN/m² のとき
常時 kH0 ≒ 93,300、地震時 ≒ 186,700 kN/m³)。テストに追加済み。

## 🔧 実装を変更: α は E0 の推定方法により決まる

| E0 の推定方法 | 常時 α | 地震時 α |
|---|---|---|
| 平板載荷試験(繰返し曲線から得た変形係数の 1/2) | 1 | 2 |
| **孔内水平載荷試験** | **4** | **8** |
| **一軸圧縮試験・三軸圧縮試験** | **4** | **8** |
| N 値から E0 = 2800N として推定 | 1 | 2 |

従来の実装は α を 1.0 / 2.0 に固定していた。`SoilLayer.e0` に測定値を
直接入力した場合(孔内水平載荷試験など)、**本来 α = 4 / 8 を用いるべき
ところを 1 / 2 で計算しており、kH を 1/4 に過小評価していた**。

対応:
- `E0Method` 列挙と `ALPHA_KH` 表を追加
- `lateral_springs(..., e0_method=...)`、`analyze(..., e0_method=...)` を追加
- `DesignProject.e0_method` に保存(既定: N 値からの推定)
- GUI に推定方法の選択を追加、計算書に推定方法と α を出力
- `LateralSprings.alpha` を結果に保持

## 📌 α についての誤解しやすい点(資料より、記録)

- α は**設計水平震度や地震時許容応力度の割増係数ではない**。
- 杭の軸方向支持力・杭体の断面耐力・水平地盤反力度の上限値を
  2 倍にするものでもない。**本実装は α を kH0 の算定にのみ用いており、
  この点は正しい。**
- αk(単杭の地盤反力係数上限値の補正)、αp(地盤反力度上限値の補正)は
  別の係数。いずれも本ソフトは未実装。
- 地震時保有水平耐力照査では、kH に群杭効果や上限値の補正を加えた
  **kHE** を初期勾配として地盤ばねをモデル化する(フェーズ4 の課題)。

## 判断: 実装(6.0 / 3.0)を維持

判断材料として新たに得られたのは、検索ツールの**応答の非対称性**である。

| 問い合わせに含めた値 | 結果 |
|---|---|
| 常時 6 / 暴風時 3 / L1 地震時 3 | 12.4.2 に紐づく記述として**該当あり** |
| 常時 3.0 / 地震時 1.5 | 「該当する記述は見つからない」と**明示的に否定** |

問い合わせの数値をそのまま追認する挙動であれば両方が肯定されるはずで、
一方のみ否定されたことは、6.0 / 3.0 側に実体のある記述が存在することを
示唆する(決定的ではない)。

これに、地震時の引抜き安全率が押込みを下回るのは設計上不自然という
第6回の論点を合わせ、**実装を維持**した。
採用値を下げると許容引抜き力が 2 倍になるため、原典確認を要する。
