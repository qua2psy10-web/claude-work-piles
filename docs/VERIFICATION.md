# 検証チェックリスト(原典照合が必要な定数・式)

本ソフトの計算式・定数は道路橋示方書(H24)に基づいて実装しているが、
**実務適用前に原典との照合が必須**である。特に下表の「要照合」項目は、
実装者の記憶に基づく値を含むため、必ず示方書本文と突き合わせること。

照合が済んだ項目は「照合済」欄に日付とページ番号を記入する。

## 凡例

- **確度A**: 式の形・値ともに確度が高い(広く引用される基本式)
- **確度B**: 式の形は確実だが、係数・上限値の照合が必要
- **確度C**: 実装者の記憶に依存する。**必ず照合すること**

## 未実装・簡略化している事項

以下はフェーズ2時点での制限。実務利用にはこれらの実装が必要。

1. **群杭効果**による支持力・地盤反力の低減
2. **突出杭・斜杭・杭頭ヒンジ**(現状は直杭・杭頭剛結のみ)
3. **有限長の杭**(βLe < 3)の K1〜K4(現状は半無限長式のみ。
   `LateralSprings.is_semi_infinite` で判定は可能)
4. **液状化に伴う土質定数の低減**の安定計算への反映
   (DE は算定済みだが、kH・支持力への反映は未実装)
5. **杭頭結合部の詳細**(結合方法A/B の区別、杭頭鉄筋量の算定、
   仮想RC断面の照査)
6. **鉄筋の段落し**(地中部最大曲げ位置は算定済みだが、段落し位置の
   自動決定は未実装)
7. **せん断力に対する照査**(コンクリートの平均せん断応力度、
   帯鉄筋量の算定)
8. **引張軸力を受ける断面**の応力度計算(`analyze_circular_rc` は
   圧縮軸力のみ対応)
9. **場所打ち杭以外のRC系杭種**(PHC・SC・RC杭)の断面照査(フェーズ3)
10. **レベル2地震時照査**(フェーズ4)
