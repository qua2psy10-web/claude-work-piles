# 【せん断2】2026-08-12 帯鉄筋の入力と、レベル2のせん断耐力(道示Ⅳ 5.2.3)

前回のせん断照査は「必要量 Aw/s を提示する」までで、**実際の配筋と突き合わせて
いなかった**。帯鉄筋を入力に加えて、3つをまとめて埋めた。

## 1. 帯鉄筋の入力(`StirrupLayout`)

径・間隔 s・本数・角度 θ。円形断面ではせん断ひび割れを横切る帯鉄筋は
**1断面あたり 2本**(円の両側)なので既定を 2 とした。中間帯鉄筋を配置する
場合はその分を含める。

## 2. レベル1: 必要量 vs 配置量の照査

`StirrupCheck` で必要量(式(5.1.3))と配置量 Aw/s を比較する。**不足すれば
NG になる**(従来は τa2 の上限だけが合否だった)。

斜引張鉄筋の許容引張応力度は**軸方向鉄筋とは区分が異なる**ことに注意した。
表-4.3.1 で地震時の基本値は軸方向鉄筋が 200/230/290 に対し、それ以外は
**一律 200** である。したがって SD490 を用いても斜引張鉄筋は 200×1.50 = 300
であり、軸方向鉄筋の 290×1.50 = 435 とは違う。`rebar_tension_allowable()` に
`axial_rebar` 引数を足して区別した(テストで固定)。

## 3. レベル2のせん断耐力 Ps(道示Ⅳ 5.2.3)

    Ps = Sc + Ss
    Sc = cc・ce・cpt・cN・τc・b・d
    Ss = Aw・σsy・d・(sinθ + cosθ) /(1.15 s)

原典の規定に従った点:

- **cc = 1**。「橋脚の張出しばり、橋台及び基礎については cc = 1 としてよい」
- **cN は考慮する**。「軸方向圧縮力による補正は…**杭のように軸力の作用が明確な
  部材においてのみ考慮する**」。橋脚・橋台・フーチングは cN = 1 だが杭は違う
- **σsy は 345 N/mm² で頭打ち**。「斜引張鉄筋の降伏点は、従来より用いられて
  いる SD345 の降伏点を上限値としている」。SD390・SD490 を用いても 345
- τa1 ではなく **τc(表-5.2.1)** を用いる

帯鉄筋が未入力なら Ss = 0(コンクリートのみ)として算定し、その旨を注記する。
軸方向鉄筋が未入力なら照査自体を行わず、行っていないことを注記する。

# 【せん断】2026-08-12 杭体のせん断照査を実装(道示Ⅳ 5.1.3)— **原典照合済み**

第23回で原典から式・表がすべて揃ったので実装した。`core/section/shear.py`。
**丸ごと欠けていた照査がこれで埋まり、レベル1側の断面照査が一通り揃った。**

## 実装した内容

**円形断面の b・d**(図-解4.2.2 の規定をそのまま):

    b = √(π D²/4) = 0.8862 D
    d = b/2 −(引張側 1/4 部分にある鉄筋の y 座標の平均)

D = 1.0 m、24-D25、かぶり 125mm の例で b = 886.2 mm、d = 768.7 mm。
手計算(該当は 135°〜225° の 7 本、重心 y = −0.325613、b/2 = 0.443113)と
一致することをテストで固定した。

**照査**:
- τm = S /(b・d) — 杭は等断面なので式(5.1.2) の有効高変化の項は 0
- **合否は τm ≤ τa2** で決める。杭には帯鉄筋が必ず配置されるためこれが上限
- τm > τa1 は NG ではなく「**斜引張鉄筋がどれだけ必要か**」を意味する。
  式(5.1.3) で Aw/s (mm²/mm) を算定して提示する
- τa2 を超えたら鉄筋を増やしても解決しない(断面を大きくする)

**τa1 の補正**: ce・cpt・cN を乗じる。表の中間値は線形補間、範囲外は端で頭打ち。

**地震時**: τa1 × 1.50 の代わりに τc を用いる(原典 4.2 の解説)。τc は τa1 を
丸めた値の 1.5 倍と厳密には一致しないため、この区別は実際に値を変える。

## 実装上の判断(原典に書かれていない細部)

原典の規定に幅がある箇所は、**いずれも安全側**に倒した。

| 箇所 | 判断 | 理由 |
|---|---|---|
| 引張側 1/4 部分の**境界上**の鉄筋 | **含める** | 重心が上がり d が小さくなる → τm が大きく、Sca が小さくなる |
| 図心位置(y = 0)にちょうど乗る鉄筋 | **数えない** | pt が小さく → cpt が小さく → τa1 が小さくなる。浮動小数の符号揺れを避けるため許容差で明示的に決定的にした |
| pt の算定 | **図心より引張側**(簡略法) | 原典が明示的に許容。中立軸は図心より圧縮側にあるので鉄筋を少なく数える → 安全側 |
| cN | **杭では考慮する** | 原典 5.2.3 の解説に「杭のように軸力の作用が明確な部材においてのみ考慮する」とある。橋脚・橋台・フーチングは cN = 1 |

## 挙動の確認(D=1.0m、24-D25、σck=24、レベル1地震時)

## ❌ 誤り4: 鉄筋の許容応力度の体系(**一部が非安全側**)

## 2. ⚠ **適用範囲が誤っていた**(第21回の実装のバグ)

> 常時の許容支持力照査と、液状化を考慮する地震時照査を混同しない。

### 修正

- `LoadCase.is_seismic` を追加(レベル1地震時のみ真)。
- `analyze()` は支持力を**2つ**算定する。`bearing`(低減なし、常時・暴風時用)と

  で使い分ける。
- **kH への DE も同じ扱いにした**。こちらも耐震設計上の低減であり、常時・

- 計算書・GUI は、常時用の表に加えて「液状化を考慮する地震時」の節を出し、

# 【第21回】2026-08-12 液状化層の周面摩擦力度に DE を反映 — **既知の非安全側を解消(第22回で裏付け)**

## ⚠ 確度 C — 原典未確認のまま**安全側に**適用した

**これは通常の方針(未確認なら実装しない)から外れる判断である。**

1. 液状化した層が満額の周面摩擦を発揮するとは考えられず、**低減しないことが

2. 抵抗を小さくする側の扱いであり、誤っていても安全側に外れる。

### 残る技術的な疑問(原典で要確認)

本ソフトの f は **N 値相関**(f = 2N、10N など)から求めており、DE が乗じられる
「土質定数」(c・φ)そのものではない。したがって

- f に直接 DE を乗じてよいのか
- それとも c・φ を低減してから f を算定し直すのか

が未確定である。前者を実装した。**この点が分かる資料があれば確定できる。**

## 実装

- `compute_bearing_capacity(..., reduction=...)` を追加。層内で f は一定なので、
  区間の DE を**層厚加重平均**して乗じた値は ∫f・DE dz と**厳密に一致する**
  (近似ではない)。この一致を数値積分との比較でテストに固定した。
- `SkinFrictionSegment` に `de` を追加。`f` は低減前の値を保持し、`f_design`

- `BearingCapacity.skin_resistance_unreduced` で低減量を提示できる。
- **先端支持力度 qd には乗じていない**。支持層は液状化しない良質層である
  ことが前提だからである。ただし判定範囲内で先端付近が液状化すると判定された
  場合は `tip_de < 1.0` となり、**qd を低減していない旨を警告する**
  (黙って通さない)。
- レベル2にも反映した。Ru は軸方向バネの上限 Pu・Pt を直接決めるため、

  pHU そのものに DE を乗じているため、杭前面地盤の抵抗としては低減が効いている。

# 【第20回】2026-08-12 提供資料(SC杭の EI 評価)— **合成断面と Ec が確定**

## 資料

## 1. 結論: **合成(換算)断面で評価する**(確度 B)

> SC杭の杭体曲げ剛性 EI は、原則として鋼管とコンクリートをともに考慮した
> 合成(換算)断面で評価する。**鋼管のみの EI を標準入力にする扱いではない。**

    EI = Ec・Ic + Es・Is

**本ソフトの実装は元から正しかった**。`_sc_section` は鋼を基準とした換算断面
(E = Es、I = Is + Ic/n、n = Es/Ec)としており、展開すると

    EI = Es・(Is + Ic・Ec/Es) = Es・Is + Ec・Ic  ✓

と定義式に一致する。軸方向も EA = Es・As + Ec・Ac となり Kv と整合する。
この恒等性を `test_sc_pile_stiffness_equals_ec_ic_plus_es_is` で固定した。

資料が挙げる「避けるべき設定」— **コンクリート基準で整理された Ie(= Ic + n・Is)
に Es を掛ける** — は鋼管の寄与を重複計上して EI を過大にする。同テストで、
その誤った値が正しい値より大きくなることも併せて固定している。

## 2. **SC杭のコンクリートは Ec = 3.5×10⁴ N/mm²**(H24版)

| 材料 | ヤング係数 |
|---|---|
| 鋼管 | Es = 2.0×10⁵ N/mm² |
| SC杭のコンクリート | **Ec = 3.5×10⁴ N/mm²** |
| ヤング係数比 | n = Es/Ec = 5.71 |

`standards.EC_SC_PILE_CONCRETE = 3.5e7` として実装した。SC杭は **σck から
表引きしない**(`_sc_section` は fck を受け取らなくなった)。

注目すべき点として、**3.5×10⁴ は表-3.3.3 の σck = 60 の値と一致する**。
SC杭のコンクリートは σck = 80 だが、表が 60 で終わっているため外挿せず
上限で頭打ちにしている、と解釈できる。第19回で確定した「表は 60 まで」と
整合しており、この符合自体が値の傍証になっている。

## 3. 裏取りの状況(確度 B にとどめた理由)

**独立の確認は取れなかった**。資料が挙げる3出典(土木研究所資料 d4374v2、

# 【M-φ】2026-08-12 鋼管杭の M-φ を BNWF に載せる試み — **見送り**

分布バネモデルに要素ごとの M-φ(バイリニア、Mp を上限)を組み込もうとしたが、
**信頼できる状態にできなかったため取り込みを見送った**。同じ失敗を繰り返さない
よう、判明したことを記録する。実装の試作は破棄した(本文書の内容で再現できる)。

## 判明したこと1: 完全弾塑性の分布塑性は、この境界条件では解が存在しない

Mp を上限とする完全弾塑性(降伏後の剛性 0)で、杭頭変位を与えて解こうとすると
釣合いが成立しない。理由は式で示せる。

梁の釣合いは EI・y'''' = −kH・D・y、すなわち M'' = −kH・D・y である。
塑性域では M ≡ Mp(一定)なので M'' = 0、したがって **y = 0** でなければ
ならない。杭頭に有限の変位を与えたまま塑性域が有限の長さに広がると、この
条件と矛盾する。

数値的にもそのとおりになる。残差が消えない自由度を調べると、**塑性域の内部の
並進自由度**(変位が 4.8 mm ある節点)に集中していた。反復の失敗ではなく、
解が存在しない状態である。

塑性域が「点」(塑性ヒンジ)なら矛盾しない。そこで杭頭の回転を解放して
M = ±Mp を与える定式化も試したが、離散化した要素は有限長なので、その要素が
全塑性になった時点で同じ問題が起きる。

## 判明したこと2: 正則化すると解けるが、結果が正則化パラメータに依存する

降伏後に小さな剛性 r・EI を残す(ひずみ硬化による正則化)と解ける。
r → 0 で収束はするが、収束が遅い。

| r | u = 20 mm での杭頭水平力 H |
|---|---|
| 1e-2 | 1523 kN |
| 1e-3 | 1325 kN |
| 1e-4 | 1280 kN |
| 1e-5 | 1274 kN |
| 1e-6 | **収束しない** |

r = 1e-4 なら極限値との差は 0.5% 程度で、実用上は許容できる。しかし
**道示のモデルには存在しないパラメータ**であり、これを既定値として
設計計算に用いることには抵抗がある。

## 判明したこと3(決め手): 分割数を細かくすると収束しなくなる

r = 1e-4 で n = 200 分割は解けるが、**n = 400 分割では収束しない**。
分割を細かくすると壊れる非線形ソルバーは、設計計算には使えない。
これが取り込みを見送った直接の理由である。

## 副産物: 構成則の積分と整合接線は正しく作れた

行き詰まったのはソルバーの頑健性であって、定式化ではない。次の点は
確認できているので、再挑戦するときに使える。

- 構成則は **Gauss 点で積分**する(∫Bᵀ M(φ) dx)。要素ごとに一つの曲げ剛性を
  割り当てる簡便法では、剛性が飛ぶ境界でモーメントが一意にならず、釣合い残差が
  原理的に消えない(残差が回転自由度に居座る現象として現れた)。
- 弾性状態では Gauss 積分が解析的な Hermite 剛性マトリクスと厳密に一致する
  ことを確認済み。
- 接線は **Gauss 点ごとに**降伏を判定して組む。要素単位で判定すると収束が
  1次に落ち、200 回以上の反復を要した。整合接線にすると 1〜5 回で収束した。
- 反復の初期値は、前回の解の杭頭自由度だけを差し替えてはならない。杭頭要素
  だけが折れ曲がった状態になり、実際には降伏しないのに塑性域と誤認する。
  杭頭変位の増分に対する内部自由度の応答を接線剛性で解いた**増分予測**から
  始める必要がある。
- Gauss 点のモーメントは Mp で正しく頭打ちになっていた(510 / Mp = 500)。
  一方、**杭頭の節点反力 C1 は断面のモーメントそのものではない**ため、
  塑性域では両者が乖離する(563 対 510)。報告する値の取り方に注意が要る。

## 再挑戦するなら

1. 分割数への頑健性を先に確保する(荷重増分の細分化、弧長法、あるいは
   分布塑性ではなく**集中塑性ヒンジ**による定式化)。
2. 集中塑性ヒンジのほうが、判明したこと1 の「塑性域は点でなければならない」
   という性質に素直で、正則化パラメータも不要になる可能性が高い。
3. 現状のまま残っている制限は「杭体が弾性 EI のまま」である。これは資料が
   「よくある誤り」に挙げている状態であり、**引き続き解消すべき課題**。

# 【DE反映】2026-08-12 液状化の低減係数を安定計算に反映 — **既知の非安全側を解消**

液状化判定で DE を算定していながら、**どこからも使われていなかった**
(`analyze()` は液状化判定の結果を引数に取ってすらいなかった)。
第7回で「側方地盤のバネ定数 kH に DE を乗じる」ことを確認済みだったため、
資料を追加せずに繋ぎ込んだ。

## 実装

`SoilReduction`(`core/soil/liquefaction.py`)として、液状化判定の結果から
深度ごとの DE を取り出す。適用先は解析方法で異なる。

| 解析 | 適用方法 |
|---|---|
| 杭頭バネ K1〜K4(常時・暴風時・L1) | kH の平均区間(杭頭直下 1/β)で**層厚加重平均**した DE を kH に乗じる |
| 分布バネモデル BNWF(L2) | **節点ごと**に DE をバネ定数と上限値に乗じる |

平均化は、kH が杭全長で1つの値しかない弾性モデルの制約による近似である。
分布バネモデルでは層ごとに扱えるため、そちらのほうが原典に忠実である。

### 低減は収束計算の**内側**で行う

kH に後から DE を掛けるだけでは β が変わらない。β = ⁴√(kH・D/4EI) なので、
低減を収束計算の内側に入れることで kH の低下が β の低下として伝わり、
**地中部最大曲げモーメントの位置が深部へ移動する**。これは第7回に
「提供資料の指摘」として記録した挙動であり、テストで固定した。

実例(N = 10・FC = 25% の砂層、DE = 2/3):

| | 低減なし | 低減あり |
|---|---|---|
| 水平変位 u | 2.28 mm | **3.00 mm**(+32%) |
| β | 0.316 | 0.283 |
| 杭頭モーメント | −143 kN·m | **−197 kN·m**(+38%) |
| 地中部最大M の深さ | 3.27 m | **3.92 m** |

なお**地中部最大曲げモーメントの値そのものはほとんど変わらない**。全杭が
同一なら杭頭水平力は釣合いから決まり(H / 本数)、バネの大小によらないため。
増えるのは変位と杭頭モーメントである。テストの期待値もこれに合わせた。

## 🔧 発見: 完全液状化では Chang の式が適用できない

杭頭直下が全て DE = 0 になると kH = 0 → β = 0 となり、収束計算が
ゼロ除算で落ちた。これは実装のバグであると同時に、**モデルの適用限界**を
示している。杭頭バネ K1〜K4 は弾性床上の梁を前提とするため、杭頭直下に
水平抵抗が全く無い状態は表現できない。

ゼロ除算のまま落とすのではなく、理由と対処(分布バネモデルであれば
節点ごとに扱えるのでレベル2の照査を使う)を示すエラーにした。
実際、BNWF は同じ地盤条件で問題なく解ける。

## 適用範囲についての注意(実装で明示)

- DE は**レベル2地震動に対する液状化判定**から得られる。本ソフトは
  レベル1地震動に対する液状化判定(khg0 が異なる)を実装していないため、
  **常時・レベル1地震時の照査に用いるかは利用者の判断**とし、GUI では
  明示的なチェックボックスで opt-in、結果には必ず注記を出す。
- **周面摩擦力度・受働土圧強度への低減は適用していない。** 第7回で
  確認できたのは kH までである。
- BNWF では pHU(上限値)にも DE を乗じている。これは確認範囲を超えるが、
  (a) 液状化層は受働抵抗も失われると考えるのが自然、(b) 乗じないと
  バネの降伏変位 R/k が液状化層でかえって大きくなり挙動が不整合、
  (c) 抵抗を小さくする安全側、という理由による。**原典で要確認**。

## 確度の変化

|---|---|---|
| DE の kH への反映 | **未実装**(既知の非安全側) | **実装**(確度B、第7回の確認による) |

# 【BNWF】2026-08-12 分布バネモデルの実装 — **pHU を解析に反映**

第18回で pHU の値と診断までを実装したが、**解析への反映**には杭を軸方向に
分割した非線形梁モデルが必要だった。これを `core/analysis/bnwf.py` として
実装し、レベル2解析の水平方向に組み込んだ。

## モデル

- 杭を Hermite 梁要素で分割し、節点ごとに水平地盤バネを配置
- バネ定数 k_i = kH・D・Δz_i、上限値 R_i = pHU_i・D・Δz_i(弾完全塑性)
- 杭頭 2 自由度を拘束して内部自由度を Newton-Raphson で解き、
  杭頭に**静的縮約**した 2×2 接線剛性を返す
- 杭先端は自由。単調載荷なので履歴は不要(経路依存性なし)

## 符号規約の整理

変位法(:mod:`core.analysis.displacement`)の杭頭回転は **θ = −dy/dx** で
あることを、Chang の解と K1〜K4 の対応から導いた。梁要素の (y, φ) 系とは
D = diag(1, −1) による相似変換 K_(u,θ) = D・K_(y,φ)・D で結ばれる。
これを実装前に確定させたので、符号を「合うまで調整する」ことは避けている。

## ✅ 検証: Chang の解析解の再現

**これが本モデルの検証の要である。** 地盤バネが弾性で βL ≫ 3 のとき、
縮約した杭頭剛性は Chang の式に収束しなければならない。

    K_(u,θ) → ⎡ 4EIβ³  −2EIβ²⎤   (= [[K1, K2], [K3, K4]])
              ⎣−2EIβ²   2EIβ ⎦

分割数に対する最大相対誤差(EI = 10⁶、kH = 5×10⁴、D = 1.0、L = 30 m):

| 分割数 | 25 | 50 | 100 | 200 | 400 |
|---|---|---|---|---|---|
| 誤差 | 2.7% | 0.67% | 0.17% | 0.042% | 0.010% |

**2次収束**(分割を倍にすると誤差は約 1/4)を確認し、テストで固定した。
変位分布・杭頭反力・K2 = K3 の符号(負)も Chang の解と一致する。

さらに、レベル2解析全体としても「pHU を事実上無限大にすると従来の
K1〜K4 による結果に 2次で収束する」ことをテストしている。数値解なので
厳密一致はしないため、**固定の許容差ではなく収束の次数**を検証している。

## 群杭の扱い

フーチングが剛体なので全杭の杭頭変位は等しいが、砂質地盤では最前列以外の
pHU が 1/2 になるため、**最前列とそれ以外で 2 つの杭モデル**を持つ。
杭の x 座標が最大の列を最前列としている。結果として、同じ変位でも最前列の
ほうが大きな水平力を負担する(テストで固定)。

## 既定値

分割数の既定は 100。弾性状態で杭頭モーメントの誤差が 1% 程度であり、
プッシュオーバー1回あたり約 1 秒。50 分割では 4% 程度の差が出るため、
精度側に振っている。

## 解消した制限・残る制限

| 項目 | 状態 |
|---|---|
| pHU による地盤の塑性化 | **解消**(KEP を入力した場合) |
| KEP 未入力の場合 | 従来どおり弾性。診断で超過区間を提示 |
| 杭体の M-φ による剛性低下 | **未実装**(残る主な差) |
| レベル2用の kH | 未照合(レベル1の α = 2 を使用) |

制限事項の注記は解析方法に応じて切り替わる。弾性で解いた場合は
「pHU を取り込んでいない」、分布バネモデルで解いた場合は「数値解であり
分割数が粗いと差が出る」を付す。

# 【第18回】2026-08-12 提供資料(pHU・杭体 M-φ)— **フェーズ4の2大制限に着手**

提供資料2件は、フェーズ4で「意図的に実装していないもの」として掲げていた
**水平地盤反力度の上限値 pHU** と **杭体の M-φ 関係**をそれぞれ扱う。
いずれも実務的な注意点まで書かれており、これまでの提供資料の中でも
内容の密度が高い。

## ✅ pHU: 2つの pHU を混同していた可能性を回避できた

資料の最大の指摘は、**同じ記号 pHU でも対象により規定が別**という点。

| 対象 | 上限値 | 割増し係数 |
|---|---|---|
| 基礎前面地盤(ケーソン・フーチング前面) | pHU = αp・pEP | αp = min(1 + 0.5 z/Be, 3.0) |
| **杭前面地盤(杭軸直角方向)** | **pHU = ηp・αp・pU** | 土質・N値・群杭配置による |

本ソフトが必要とするのは**後者**である。前者は基礎前面の水平抵抗を
考慮する場合の規定で、本ソフトは考慮していないため実装していない。

### 実装した係数(確度B)

| 地盤 | αp | ηp | 最前列以外 |
|---|---|---|---|
| 砂質土・礫質土 | 3.0 | ηp・αp = min(s/D, αp) | pHU の **1/2** |
| 粘性土 | 1.5(N ≤ 2 は **1.0**) | 1.0 | (資料に記載なし) |

s は**載荷直交方向**の杭中心間隔。1/2 の規定は資料が砂質地盤の欄にのみ
記載しているため、粘性土には適用していない(原典で要確認)。

### ⛔ KEP(地震時クーロン受働土圧係数)は実装しない

受働土圧強度は pU = KEP・Σ(γ'ti・hi)+ 2c・√KEP で、資料は
「壁面摩擦角 δE は原則 −φ/6」まで示している。しかし KEP 自体の算定式は
地表面勾配・設計水平震度を含み、**符号の取り違えが静かに危険側に効く**
種類の式である。原典照合ができない以上、推測で実装すべきではないと判断し、
**KEP は層ごとの利用者入力**(`SoilLayer.k_ep`)とした。
pU の式そのものは資料どおり実装している。

### 🔧 「反力度」と「力」の取り違え対策

資料は「pHU をばね力(kN)として直接入力する」ことをよくある誤りとして
挙げている。これに対応して、換算を :func:`spring_force_limit`
(R_max = pHU × D × Δz)に閉じ込め、テストで固定した。

### 🔧 pHU を使った**診断**を追加

フェーズ4 の解析は水平地盤バネが弾性のままで、これが最大の非安全側要因
だった。分布バネモデル(BNWF)への置き換えは未了だが、**弾性モデルの
地盤反力度 p = kH・y が pHU を超える区間があるか**を診断し、超過深度と
超過率を提示するようにした。制限を「弾性である」という定性的な注記から、
**どの深さでどれだけ非安全側か**という定量的な情報に変えている。

フーチングを剛体としているため全杭の y(x) は等しく、pHU は砂質地盤で
最前列以外が 1/2 になる。したがって**最前列以外の杭が支配する**ので、
2列以上ある場合はそちらで判定している。

## ✅ M-φ: 杭種によるモデル形と、鋼管杭の Mp

| 杭種 | モデル | 上限・折れ点 |
|---|---|---|
| 場所打ちRC杭・PHC杭・SC杭 | トリリニア型 | ひび割れ C・降伏 Y・終局 U |
| 鋼管杭・鋼管ソイルセメント杭 | **バイリニア型** | **全塑性モーメント Mp** |

### 🔧 実装の誤りを修正: 鋼管杭は Mp であって My ではない

フェーズ4 では鋼管杭の杭体降伏を**最外縁が降伏点に達するモーメント**
My =(σy − N/A)・Z で判定していた。資料により、道示のモデルは
**全塑性モーメント Mp を上限とするバイリニア型**であることが確認できたため、
判定を Mp に変更した。My は参考値として併記する。

Mp は薄肉円環断面の完全塑性状態を解いて求めた。塑性中立軸の角度を θ0 と
すると N = −4σy・t・r、M = 4σy・t・r²・cos θ0 から

    Mp(N)= 4・σy・t・r²・cos( π・N /(2・Np) ),  Np = σy・A

これは**導出できる厳密解**であり、記憶に頼った定数ではない。中実解
Zp =(D³ − d³)/ 6 と 1% 以内で一致することをテストで固定した

.. note::

   鋼管杭の D/t では 0.1% 程度の差であり、実用上の影響は小さい。

### ❌ トリリニア型は未実装

C(ひび割れ)・Y(降伏)・U(終局)の各点は、断面配筋・材料の応力-ひずみ

実装方針の裏付けとして記録する。

- αp = 3.0 を全ての pHU にそのまま用いる
- pHU をばね力(kN)として直接入力する
- 良質性を確認していない埋戻し土の抵抗を算入する

# 【第17回】2026-08-12 提供資料(道示Ⅴ 表10.2.1)— **資料は橋脚だが、杭基礎の規定に到達**

提供資料は「H24 道示Ⅴ 許容塑性率・許容変位(RC橋脚)」の技術整理メモ。
**本ソフトが必要としていたのは杭基礎の規定であり、資料が扱うのは橋脚**
だったが、これを起点とした調査で杭基礎側の規定に到達できた。

## 資料そのものの評価

### ✅ 第5回で記録した式の形が確認できた

    μa = 1 +(δu − δy)/(α・δy)= 1 +(μu − 1)/ α
    δa = μa・δy = δy +(δu − δy)/ α

第5回に記録した式と一致する。**表10.2.1 は許容塑性率の一覧ではなく、
終局変位から許容値を求めるための安全係数 α の表**である、という位置づけの
説明も得られた。

### ⛔ 安全係数 α の値は採用しなかった

資料は「耐震性能2・3とも α = 1.2」とする。しかし、

1. **2行とも同じ値なら表にする意味がない**という内部矛盾がある
2. 検索では「H14 道示Ⅴ は耐震性能2・タイプII地震動に対して 1.5」という
   記述が確認でき、第5回に記録した 1.5 と整合する
3. 「耐震性能2・3ともに 1.2」で照会したが、裏付けは得られなかった

H14 では(耐震性能, 地震動タイプ)の2次元表で、H24 でタイプの区別が
なくなった経緯がある。そうであれば H24 の表は
**耐震性能2 → 1.5、耐震性能3 → 1.2** となるはずで、資料の「ともに 1.2」は
耐震性能2 の行を取り違えた可能性が高い。

いずれにせよ **α は RC橋脚の規定であり、杭基礎には適用しない**。
本ソフトは橋脚本体を設計しないため、実装には取り込んでいない。

## ✅ 本題: 杭基礎の許容塑性率・許容変位(**確度B、新規実装**)

資料をきっかけに道示Ⅴ 12.4 / Ⅳ 12.10 側を調査し、次を得た。

|---|---|
| 許容塑性率 μa(橋脚の杭基礎、直杭) | **4** |
| 許容塑性率 μa(橋台の杭基礎、直杭) | **3** |
| 許容変位 | **フーチング底面位置の回転角 0.02 rad** |
| 場所打ち杭に SD390・SD490 を用いる場合 | 橋脚 **2**、橋台は**塑性化を考慮できない** |
| 斜杭の場合 | 橋脚 3 / 橋台 2(本ソフトは斜杭に未対応のため未登録) |

### 裏取りの経緯

- 独立した検索2件が μa = 4 / 3 と回転角 0.02 rad で一致
- **バイアス確認**: 「橋脚 6 / 橋台 5」で照会したところ、検索側は
  「その数値は引用されていない」と明示的に否定した。第9回と同じ方法で、

二次資料は 0.02 rad に「約1/60rad」と併記するが、**0.02 rad = 1/50 rad**

コメントとテストに残した(1/60 を採るとより厳しくなるため、原典で要確認)。

- 水平変位の制限は「道示の規定ではなく利用者が指定した値」と明示したうえで

これによりフェーズ4 で「利用者の入力に委ねる」としていた 2 項目

## 意図的に実装していないもの(`LIMITATIONS` として結果に添付)

1. **水平地盤反力の非線形**(水平地盤反力度の上限値 pHU による塑性化)。

2. **杭体の M-φ 関係**。塑性ヒンジ後の剛性低下を追跡していない。
3. レベル2用の水平方向地盤反力係数 kH(現在はレベル1の α = 2 を使用)。
4. 液状化に伴う地盤定数の低減、群杭効果、側方流動。

c) 釣合いが保てなくなる(変位の急増)

道示Ⅳ 12.10 / Ⅴ の規定に基づく整理だが、**原典との照合は済んでいない**。

## 🔧 **先端面積 A の工法別規定**(新たに判明した誤り)

> 先端面積 A: 鋼管ソイルセメント杭は**ソイルセメント柱断面積**、
> 回転杭は**羽根投影面積 Aw**。杭の鋼管断面積ではない。

実装は全工法で A = πD²/4(杭径基準)としており、**Ru = qd・A の A 自体が
誤っていた**。

| 工法 | 正しい A |
|---|---|
| 鋼管ソイルセメント杭 | ソイルセメント柱の断面積 |
| 回転杭 | 先端羽根の投影面積 Aw(羽根外径 = 比 × 杭径) |
| その他 | 杭径による円の面積 |

例: D=1.0m・羽根1.5倍の回転杭の Aw = 1.767 m²(杭径基準の 0.785 m² の 2.25倍)。

対応:
- `tip_area(pile)` を新設し、工法別に基準径を切り替える
- `PileSpec.soil_cement_diameter` を追加。鋼管ソイルセメント杭で未入力なら
  **エラー**(黙って鋼管径を使うと A を大幅に過小評価するため)
- 鋼管ソイルセメント杭は**周長 U** もソイルセメント柱径を用いることとした
  (資料は A のみ言及。地盤と接するのがソイルセメント柱であることによる
  物理的整合からの判断で、**原典未確認**)
- GUI に羽根外径比・ソイルセメント柱径の入力を追加

# 【第13回】2026-08-12 提供資料(中掘り杭の qd)— **重大な欠落を2件修正**

出典が3つ明記された最も質の高い資料(日本道路協会 原典、原子力規制委員会
公開資料、土木研究所資料 第4303号)。第1回から保留していた
「中掘り系の qd 上限は 12,000 か 10,000 か」が決着し、**それ以前に実装が
規定の構造そのものを取り違えていた**ことが判明した。

## 🔧 欠落1: 中掘り杭は先端処理方式により qd の算定法が変わる

| 先端処理方式 | qd |
|---|---|
| 最終打撃方式 | **打込み杭の算定法を適用**(150N/200N は用いない) |
| セメントミルク噴出攪拌方式 | 砂層 **150N(≦7,500)**、砂れき層 **200N(≦10,000)** |
| コンクリート打設方式 | **場所打ち杭の極限支持力度を適用** |

従来の実装は中掘り杭を一律「砂質土・礫質土とも 200N(≦12,000)」としていた。
資料が「よくある混同」として挙げる **「中掘り杭は qd = 200N」は誤り** に
そのまま該当していた。

実際の差(N = 40 の場合):

| 先端処理方式 | 砂層 | 砂れき層 |
|---|---|---|
| 最終打撃方式 | 5,200 | 5,200 |
| セメントミルク噴出攪拌方式 | 6,000 | 8,000 |
| コンクリート打設方式 | 3,000 | 3,000 |
| **旧実装(誤り)** | **8,000** | **8,000** |

砂層で最大 2.7 倍、コンクリート打設方式では 2.7 倍の過大評価だった。

対応:
- `TipTreatment` 列挙(最終打撃 / セメントミルク / コンクリート打設)を追加
- `PileSpec.tip_treatment` を追加(既定はセメントミルク噴出攪拌方式)
- `qd_method_key()` が先端処理方式に応じて参照する工法を切り替える
- GUI に先端処理方式の選択を追加

## 🔧 欠落2: 場所打ち杭の qd は N 値の区分により変わる

| 支持層の区分 | qd (kN/m²) |
|---|---|
| 砂れき層および砂層(**N ≧ 30**) | 3,000 |
| **良質な砂れき層(N ≧ 50)** | **5,000** |
| 硬質粘性土層 | 3qu |

従来の実装は砂質土・礫質土とも一律 3,000 の定数としており、

- **N ≧ 50 の良質な砂れき層で 5,000 を使えない**(過小評価、安全側)
- **N < 30 でも 3,000 を与えてしまう**(過大評価、**危険側**)

という双方の誤りがあった。

対応:
- `QdSpec` に "steps" 種別を追加(N の閾値ごとの一定値)
- 砂質土 = ((30, 3000),)、礫質土 = ((50, 5000), (30, 3000))
- N が最小の閾値未満なら「支持層の条件を満たさない」として **ValueError**

## ✅ qd 上限が確定

第1回から保留していた中掘り系の上限は、セメントミルク噴出攪拌方式で
**砂層 7,500 / 砂れき層 10,000** と確定。旧実装の 12,000 は誤りだった。
(第1回に見つけた国総研資料の「10,000」は砂れき層について正しかった。)

## 📌 記録: 適用の前提

- セメントミルク噴出攪拌方式の支持力推定式は、載荷試験で支持力が確認され
  施工管理手法が確立した工法への適用が前提。岩盤支持や公的評価の適用範囲外
  では鉛直載荷試験を含む個別検討が必要。
- セメントミルク噴出攪拌方式は支持層へ**杭径程度以上根入れ**し、設計径は杭径。
- 岩盤・軟岩を支持層とする場合は場所打ち杭の表だけで一律に決めず、別途
  適用性の確認が必要(本ソフトは岩盤を土質区分として持たない)。

## 確度の変化

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 中掘り杭の qd(先端処理方式別) | C(構造ごと誤り) | **A** |
| 中掘り杭の qd 上限 | C(12,000) | **A**(7,500 / 10,000) |

## ⛔ 採用しなかった部分と、その理由

提供資料2(表-12.4.2 = 杭先端極限支持力度)に記載された qd の値は、
これまでに確認した道示準拠の公開資料と系統的に食い違う。

| 工法 | 提供資料の値 | 本ソフト実装値 | 公開資料(道示準拠) |
|---|---|---|---|
| 打込み杭 | qd = **300N**(N≦100、上限15,000) | qd = 130N(上限6,500) | **qd = 130N(≦6,500)** |
| 場所打ち杭 | qd = **300N**(N上限60、≦10,000) | qd = 3,000(一定) | **qd = 3,000 kN/m²** |
| 中掘り杭 | qd = 200N〜300N | qd = 200N | (200N 系で整合) |
| プレボーリング杭 | qd = 200N〜250N | qd = 200N | (200N 系で整合) |

判断の根拠:

1. **打込み杭の 300N は建築系の値である可能性が高い。** 建築基礎構造設計指針
   では打込み杭の先端支持力度に 300N 系の値を用いるが、道示は 130N である。
   北海道開発局の道示準拠資料、日鉄建材、鋼管杭・鋼矢板技術協会(JASPP)の
   いずれも 130N(≦6,500)で一致しており、独立した複数ソースが実装値を支持する。
2. **場所打ち杭の 3,000 kN/m²(N非依存の一定値)も複数資料で確認済み**であり、
   提供資料の「300N」とは式の形そのものが異なる。
3. **数値の書き方が示方書の表と異なる。** 「200N〜300N」「根固め液の有無や
   セメントミルク噴射仕様により変動」「限界値あり」といった幅を持たせた
   記述は、確定値を与える示方書の表の体裁ではない。
4. **表番号の対応が公開資料と整合しない。** 提供資料は 12.4.1 = 安全率、
   12.4.2 = 先端支持力度としているが、公開資料では 表-12.4.1 が支持力推定式
   として引用されている例が複数ある。
5. 提供資料1の許容支持力式 `Ra =(1/n)Ru − Wp` は、道示の
   `Ra =(1/n)(Ru − Ws)+ Ws − W` と異なる(置換土重量 Ws の項が無い)。
6. 提供資料1は液状化による低減係数を「DL」と表記しているが、道示Ⅴの表記は
   「DE」である。また「安全係数 FL」とあるが FL は液状化抵抗率である。

以上より、両資料は**示方書本文の転記ではなく、二次的に作成された解説**
(生成AIによる作成を含む)であり、数値の信頼性が担保されないと判断した。
**qd・f の定数は変更していない。**

## ✅ 採用した部分(独立の裏付けがあるもの)

提供資料の記述のうち、以前からの独立調査と一致し、かつ安全側に働く
以下の2点を実装に反映した。

## 杭種別の対応状況(2026-08-12 時点)

断面諸元(A・I・E)は幾何と材料力学のみで決まるため全杭種で算定でき、
**支持力・バネ定数・変位法・断面力分布は全杭種で利用できる**。
一方、杭体の応力度照査は杭種ごとに許容応力度が必要で、未照合の杭種がある。

| 杭種 | 断面諸元 | 支持力・変位 | 杭体の応力度照査 | 未対応の理由 |
|---|---|---|---|---|
| 場所打ち杭 | ✅ | ✅ | ✅ | — |
| 鋼管杭 | ✅ | ✅ | ✅ | — |
| 鋼管ソイルセメント杭 | ✅ | ✅ | ✅(鋼管として) | — |
| PHC杭 | ✅ | ⚠️ | ✅(全断面有効) | σck=80 の Ec は道示Ⅲ の表にない。Ec を直接入力できる |
| SC杭 | ✅(合成断面) | ✅ | ❌ | 鋼管とコンクリートの応力度分担、鋼管部の許容応力度 |
| RC杭 | ✅ | ✅ | ❌ | 中空断面のひび割れ断面解析(鉄筋配置の入力)が未実装 |
| H鋼杭 | ✅ | ❌ | ❌ | 断面・座屈・曲げ圧縮等の照査条件が不足(資料の警告による) |

- H鋼杭は**先端面積・周長が円形断面で表せない**ため支持力も未対応
  (道示における H鋼杭の先端面積の扱いが未照合)。
- PHC杭の「⚠️」は、標準の σck = 80 に対するヤング係数が
  **道示Ⅲ 表-3.3.3(21〜60)の範囲外**で規定されていないことを示す
  (第19回)。`PileSpec.concrete_young` にメーカーの断面性能表等の Ec を
  直接入力すれば解消する。未入力なら入力した σck の Ec を用いるため
  断面力・変位が影響を受け、計算書・GUI に注記が出る。
- SC杭は第20回で解決した。合成断面 EI = Ec・Ic + Es・Is、
  Ec = 3.5×10⁴ N/mm²(H24版。H29版は 4.0×10⁴)。σck には依存しない。
- 応力度照査が未実装の杭種でも安定計算は実行され、省略した照査は
  計算書・GUI に注記として表示される(黙って飛ばさない)。
